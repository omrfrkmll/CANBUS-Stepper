# 📐 3D CAD STEP Models & Mechanical Integration

This directory contains the exported 3D CAD models of the complete **CANBUS-Stepper v1.0** PCB assembly.

---

## 📦 Files Included

- **`canbus-stepper.step`** (28.9 MB): High-detail 3D STEP assembly containing accurate 3D CAD models of all surface-mount components, connectors (USB-C, Molex Micro-Fit 3.0, JST PH/SH, FPC), tactile switches, and PCB routing geometry.

---

## 🎯 Mechanical & Mounting Specifications

| Parameter | Specification |
| :--- | :--- |
| **PCB Dimensions** | 40.3mm x 40.3mm (Chamfered corner profile with 8-fillet outline) |
| **Compatibility** | Direct rear-mount on **NEMA 17** stepper motors (42mm x 42mm) |
| **Mounting Holes** | 4x M3 screw holes (31.0mm x 31.0mm standard pitch) |
| **Magnetic Sensor Position** | AS5600 IC centered precisely on the bottom face for coaxial shaft magnet alignment |
| **Recommended Magnet Gap** | 0.5mm – 1.5mm air gap between motor shaft diametral magnet and AS5600 package |

---

## 💻 CAD Software Compatibility
These STEP models can be imported directly into:
- Autodesk Fusion 360 / Inventor
- SolidWorks
- FreeCAD
- Blender / OnShape

Use these models to design custom 3D printed enclosures, toolhead brackets, cooling fan shrouds, and robotic joints.
